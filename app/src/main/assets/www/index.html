Le solide ionique

Le chlorure de sodium est un empilement régulier d'ions Na⁺ et Cl⁻.

Modèle
  • Chaque Na⁺ est entouré de 6 ions Cl⁻.
  • Cohésion : attraction électrostatique entre ions de signes opposés.
  • Autant de charges + que de charges − : le cristal est neutre.

Dissolution de NaCl

NaCl(s) → Na+(aq) + Cl−(aq)
  1. 1. Dissociation : l'eau détache les ions du cristal.
  2. 2. Hydratation : chaque ion s'entoure d'eau. O vers Na⁺, H vers Cl⁻.
  3. 3. Dispersion : les ions se répartissent dans la solution.

Touche une étape pour y aller directement.

Conduction du courant

AmpèremètreI = 0
  • Les cations Na⁺ migrent vers la cathode (−).
  • Les anions Cl⁻ migrent vers l'anode (+).
  • Dans les fils, ce sont les électrons qui circulent.
